# borepix-web: rules for AI coding sessions

Read these before changing anything, in this order:

1. `docs/security/security.md`, `docs/security/auth.md`, `docs/security/env.md`,
   `docs/security/RLS-policies.md`, `docs/security/threat-model.md`. They are binding. Any change that
   adds a server endpoint, cookie, environment variable, database table, third-party script or payment
   step must satisfy them and must re-run the checklist in `docs/security/audit-2026-11-13.md`.
2. `design-system/ECOSYSTEM.md` and `design-system/MASTER.md` for the UI contract, copy rules and the
   Alpha/Beta release mode (`release` in `src/lib/site.ts`).
3. `AGENTS.md` (generated by Next.js): this is Next.js 16 with Cache Components; verify any Next API
   against `node_modules/next/dist/docs` before using it.

Non-negotiables:

- Never add a `NEXT_PUBLIC_` variable that holds a secret; never commit `.env*` files other than
  `.env.example`. `npm run build` enforces this via `scripts/check-env.mjs`.
- Every form input is parsed with the Zod schemas in `src/lib/schemas/`; server actions and route
  handlers must parse with the same schemas before touching any store or database.
- Sessions live only in HTTP-only cookies (`src/lib/server/session-cookie.ts`); `/admin` stays gated by
  `src/proxy.ts`.
- Do not extend the Content Security Policy in `next.config.ts` without documenting the reason in
  `docs/security/security.md`.
- Legal copy lives in `src/lib/content/legal.ts` and renders at `/terms`, `/privacy`, `/disclaimer`,
  `/dmca`, `/legal/refunds` and `/legal/trademarks`; keep "Borepix LLC" as the entity and
  `legal@borepix.com` for copyright matters.
- "Radiologic Technologists" is always capitalized; the company is in Kearny, New Jersey; support is
  info@borepix.com.

Verification before finishing: `npx tsc --noEmit`, `npx eslint src`, `npm run build`, and a browser
check of any route touched (dev server: `.claude/launch.json` → `borepix-web` on port 3100).
